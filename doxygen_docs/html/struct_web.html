Detailed Description

Represents a single web (a union of overlapping live ranges for a specific variable).

We use this structure to track a variable's lifetime throughout the code. Ultimately, each Web will become a node in our interference graph!

◆ interferesWith()

bool Web::interferesWith ( const Web & other) const
inline

Handy helper function to check if this web intersects with another one.

This will be the core logic to build the edges of our interference graph. If we find even one common active line between the two webs, boom, they interfere.

Parameters
otherThe other web we are checking against.
Returns
true if the webs share at least one active line, false otherwise.


Time Complexity:\n O(N log M), where N is the number of active lines in this web,
and M is the number of active lines in the other web (due to the std::set::find lookup).

int Web::assignedRegister = -1

The physical register assigned by our graph coloring algorithm.

According to the spec, we start with no assignment (-1). If it remains -1 after the algorithm runs, it means we must spill it to memory ('M').
