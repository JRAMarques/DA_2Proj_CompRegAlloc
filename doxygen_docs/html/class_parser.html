Detailed Description

Class responsible for reading the input datasets and converting them into usable data structures.

This is mostly a static utility class since we just need it to swallow files and spit out our Web objects and Config settings.

Reads the live ranges file and merges overlapping ranges into distinct Webs.

This function will do the heavy lifting of reading the lines, looking for '+' and '-', and merging continuous usages of the same variable into a single Web object.

Parameters
filenameThe path to the ranges.txt file.
Returns
std::vector<Web> A list of fully built Web objects ready for the interference graph.


Time Complexity:\n O(N^2 * L) where N is the number of raw live ranges parsed and L is the average number of active lines per range.
